Google Docs 實務應用總覽

歡迎來到 Google Docs（Google 文件）工具篇講義！本研習單元專為教師與教育行政人員設計，聚焦於如何靈活運用 Google Docs 的進階功能，提升教學素材製作與班級行政處理效率。

💡 本章七大實務演練目標：

  • 演練一：運用智慧型畫布 (Smart Canvas) 的使用者與日期智慧型方塊，指派負責人與截止日期。
  • 演練二：正確套用段落樣式 (Paragraph Styles)，一鍵生成動態導覽目錄。
  • 演練三：活用快捷鍵 Ctrl + H 批次尋找與取代全篇錯字。
  • 演練四：點選選單「翻譯文件」，生成多語言版本的雙語班級通訊。
  • 演練五：透過 Workspace Marketplace 安裝擴充外掛，提供非同步語音回饋。
  • 演練六：結合會議紀錄與批註 +Email 指派團隊任務。
  • 演練七：用表格與超連結做出讓學生自選路徑的探索學習單。

核心功能演練一

智慧型畫布 (Smart Canvas) 與團隊任務指派

在 Google Docs 中輸入 @ 符號，即可觸發「智慧型畫布」快捷選單。這能讓文件從單純的文字編輯器，升級為動態的團隊專案管理中心。

【實務教學情境】：
您正在為校內專案團隊編輯一份「運動會籌備會議紀錄」文件。為了讓團隊學生與教師能清楚知道各自負責的硬體租借（如音響舞台、遮陽帳棚）與秩序冊印製等工作，您需要為不同任務指派具體負責人，並訂定各項任務的完成截止期限。
📄 本單元練習方式：複製一份範本，改壞了也沒關係 📄 建立我的專屬副本
範本：運動會籌備會議紀錄 (智慧晶片演練)（Task 02 ‧ Google Docs）
點按鈕後會問你「要建立副本嗎」，按下去就會在你自己的雲端硬碟產生一份，怎麼改都不會影響別人。
🎯 你要做的事：請在「負責人」欄位輸入 @ 再打姓名／Email 插入使用者智慧型方塊；在「完成期限」欄位輸入 @date 插入日期智慧型方塊！

核心功能演練二

結構化排版與動態導覽目錄 (Paragraph Styles)

要讓長篇文件自動生成方便點選跳轉的目錄，必須正確套用段落樣式（如：標題 1、標題 2），而不是單純手動放大字體。這也是 Level 2 最常考的排版觀念。

【實務教學情境】：
您正在準備一份包含多個章節的「校本課程實施計畫手冊」，內容涵蓋課程發展願景、全學期領域配課與多元評量規範。您希望建立一份結構嚴謹的文件，讓開啟檔案者能透過最上方的目錄快速點選跳轉至指定章節。
📄 本單元練習方式：複製一份範本，改壞了也沒關係 📄 建立我的專屬副本
範本：校本課程實施計畫手冊 (段落樣式與目錄演練)（Task 03 ‧ Google Docs）
點按鈕後會問你「要建立副本嗎」，按下去就會在你自己的雲端硬碟產生一份，怎麼改都不會影響別人。
🎯 你要做的事：請選取文件中的「第一章、第二章、第三章」章節標題套用「標題 1」段落樣式，並在頂部點選「插入 ➔ 目錄」！

核心功能演練三

高效內文檢索與批次修正 (Find and Replace)

在整理多頁報告或教學素材時，使用快捷鍵 Ctrl + H 可在數秒內完成全篇文件的搜尋與取代。

【實務教學情境】：
您編輯完一份長達 10 頁的「全校週報」稿件後，才發現自己將本學期新到任的校長姓名全篇都誤打成了舊校長姓名陳大文。您需要快速定位並將所有錯字一次性更正為新校長姓名 張小明。
📄 本單元練習方式：複製一份範本，改壞了也沒關係 📄 建立我的專屬副本
範本：全校週報範例 (尋找與取代演練)（Task 01 ‧ Google Docs）
點按鈕後會問你「要建立副本嗎」，按下去就會在你自己的雲端硬碟產生一份，怎麼改都不會影響別人。
🎯 你要做的事：請按下快捷鍵 Ctrl + H 開啟「尋找與取代」，將文件中所有的「陳大文」一次全部取代為「張小明」！

核心功能演練四

跨語言親師溝通與文件一鍵翻譯 (Translate Document)

Google Docs 內建機器翻譯引擎，免安裝外掛即可將全篇文件複製並翻譯為全球數十種語言，原始文件完全不受影響。

【實務教學情境】：
身為導師，您每週都會編寫「班級每週學習通訊」發送給家長。為了讓班上不同母語背景（如越南語、印尼語、英語）的家長也能無障礙閱讀班級動態與親師座談會通知，您需要快速產出一份完整的翻譯版本。
📄 本單元練習方式：複製一份範本，改壞了也沒關係 📄 建立我的專屬副本
範本：班級每週學習通訊 (多語言翻譯演練)（Task 05 ‧ Google Docs）
點按鈕後會問你「要建立副本嗎」，按下去就會在你自己的雲端硬碟產生一份，怎麼改都不會影響別人。
🎯 你要做的事：請點選選單「工具 ➔ 翻譯文件」，選擇目標語言（如越南語或印尼語），生成一份完整的翻譯新文件！

核心功能演練五

非同步語音註解與多媒體回饋 (Marketplace Add-ons)

若希望針對學生的作文或作業給予更具親和力、非同步的「口頭回饋」，可安裝第三方工具擴充。注意兩條不同的安裝管道：Google 官方的 Workspace Marketplace（擴充功能 ➔ 外掛程式），以及 Chrome 線上應用程式商店——語音回饋工具 Mote 屬於後者。

【實務教學情境】：
學生在 Google Docs 提交了期末作文〈那一刻，我長大了〉。您希望除了文字批改外，還能錄製一段親切的口頭說明，給予學生非同步的聽覺建議與鼓勵——尤其對閱讀理解較弱的學生特別有效。
📄 本單元練習方式：複製一份範本，改壞了也沒關係 📄 建立我的專屬副本
範本：國文作文範本 (語音回饋外掛演練)（Task 04 ‧ Google Docs）
點按鈕後會問你「要建立副本嗎」，按下去就會在你自己的雲端硬碟產生一份，怎麼改都不會影響別人。
🎯 你要做的事：請到 Chrome 線上應用程式商店安裝 Mote 擴充功能並登入，重新整理文件後在作文段落新增註解、錄製一段語音回饋！

核心功能演練六

跨軟體行政整合（會議紀錄與批註指派）

Google Docs 能與 Calendar 及 Slides 深度連動，實現一鍵開立會議紀錄與批註指派任務。批註中輸入 +Email 並勾選「指派」，對方會收到含待辦的通知信。

【實務教學情境】：
教研團隊正在進行教學專案討論，開啟了「教研會會議紀錄」文件供所有人共同編輯與腦力激盪。討論結束後，您要把「下週前完成教材試教」這類待辦，精確交付給特定同仁，而不是在群組裡喊一聲就算數。
📄 本單元練習方式：複製一份範本，改壞了也沒關係 📄 建立我的專屬副本
範本：教研會會議紀錄 (日曆連動演練)（Task 09 ‧ Google Docs）
點按鈕後會問你「要建立副本嗎」，按下去就會在你自己的雲端硬碟產生一份，怎麼改都不會影響別人。
🎯 你要做的事：請選取文件段落新增註解，輸入 +成員Email 並勾選「指派給…」核取方塊，交付團隊成員執行！

核心功能演練七

用表格與超連結做出讓學生自己走的探索學習單

個人化學習不必靠昂貴平台。在 Docs 裡用一個表格列出主題與工具，每格掛上超連結（影片、網站、雲端檔案、甚至同一份文件的書籤），學生就能依自己的程度與興趣選路徑走——這是最低成本的差異化教學。

【實務教學情境】：
同一個單元，班上有學生早就懂了想深入，也有學生連基本概念都還沒穩。您沒有時間為每個人設計不同教材，但希望給出一份「自助餐式」的探索清單：每個子主題都附上不同深度的資源，學生自己挑著看，您則把時間留給真正需要個別指導的人。
🔨 本單元練習方式：從零自己建一次（不需要範本檔）
🎯 你要做的事：建立一份新文件，插入一個 3 欄的表格（子主題／基礎資源／進階挑戰），每一格用 Ctrl + K 掛上超連結，並在文件開頭用「書籤」做出可跳轉的說明區。
💬 三種連結目標都試一次：外部網址（維基、教育部資源）、雲端硬碟檔案（你自己的教材，輸入關鍵字就會跳出檔案清單）、本文件的書籤或標題（插入 ➔ 書籤，再連過去）。第三種最少人知道，卻是長文件內部導覽最好用的一招。

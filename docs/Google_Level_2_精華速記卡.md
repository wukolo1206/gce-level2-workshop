## 📌 官方 6 大單元高頻考點對照速查

| 官方單元 (Unit) | 必考重點工具 | 🔑 核心操作與快捷步驟 | 💡 考題地雷與陷阱 (Pitfalls) |
| :--- | :--- | :--- | :--- |
| **Unit 1: 自動化課堂與行政任務** | Gmail, Smart Canvas, Add-ons | `from:parent` 建立篩選器自動套用標籤；輸入 `@` 帶入人員與會議紀錄範本 | 篩選器中的關鍵字條件不要設定太寬鬆；Smart Chips 需要在 Docs/Sheets 中輸入 `@` |

| **Unit 3: 系統化組織班級與素材** | Docs, Drive, Google Sites | Docs 「插入 $\rightarrow$ 書籤 (Bookmark)」與內部連結；Sites 製作數位學習歷程 | 書籤必須先在目標點建立，才能在目錄文字連結；隱藏頁面需於 Sites 頁面選單設定 |
| **Unit 4: 打造互動式自主學習** | Slides, Meet, YouTube | Slides 設定超連結連至「這份簡報中的投影片」，並將答案頁設定為「隱藏投影片」 | 隱藏投影片在一般簡報模式下不會被直接按下一頁播放出解答；問答功能在簡報者檢視中 |
| **Unit 5: 學生個人化與差異化** | Classroom, Forms, Blogger | Classroom 取消勾選「所有學生」進行個別派發；Forms 設定「根據回應跳轉至指定區段」 | **僅單選題與下拉題支援跳轉，勾選題 (Checkboxes) 不支援跳轉！** |
| **Unit 6: 分析與解讀學生數據** | Sheets (QUERY/IMPORTRANGE), Pivot Table| `=QUERY(A1:D, "SELECT A WHERE C < 60 AND D = '401'", 1)` 與 `=IMPORTRANGE()` | **`IMPORTRANGE` 首次連線必定顯示 `#REF!`，必須點選「允許存取 (Allow Access)」** |

## 🎯 考前 6 大應試金律

1. **優先選擇整合性高、自動化的方案**：如親師會談預約首選 Calendar「預約時間表」，地圖大量標註首選 My Maps「匯入 CSV」。
2. **差異化教學看個案**：Classroom 作業個別派發不需新建課程， Forms 診斷學習看區段跳轉。
3. **跨表連線首選 IMPORTRANGE**：記得第一次要有「允許存取」的授權步驟。
4. **數據動態同步用 Link**：貼上圖表至 Docs/Slides 一律選擇「連結至試算表 (Link to spreadsheet)」。
5. **善用 Open-Book Help Center**：遇到冷門操作細節，直接開啟 Google 官方 Help Center 分頁進行搜尋。
6. **測驗中隨時點選右上角 🌐 地球圖示切換語言**：若遇到中文翻譯不暢順或較為彆扭的題目，點擊畫面右上角 🌐 選單即可隨時切換成 English 核對原版專有名詞，雙向切換不會影響答題時間與計時！
